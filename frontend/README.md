I am providing a reference website screenshot. Use the reference ONLY for understanding the overall visual quality, spacing, responsiveness, card styling and navigation structure. Do NOT copy its branding, text, logo, colors or exact layout.

PROJECT

Our project is:

“Automated Camera Trap Triage and Individual Tiger Movement Intelligence System for Pench Tiger Reserve.”

The platform uses AI to process camera-trap images, remove blank images, identify individual tigers from their stripe patterns, track their locations, estimate their area occupancy/home range and detect unusual movement patterns.

The website should feel like a combination of:

- Wildlife conservation

- Artificial intelligence

- Advanced data intelligence

- Satellite/GIS mapping

- Premium technology dashboard

It should NOT look like a generic AI SaaS landing page.

HERO VISUAL

The hero must have a large realistic tiger as the main visual element.

The tiger should feel alive but remain subtle and professional.

Use a high-quality realistic tiger visual with a very subtle animation:

- slow breathing

- slight head movement

- subtle ear movement

- occasional blinking

- gentle body movement

The tiger should NOT look cartoonish.

MOUSE INTERACTION

Add subtle mouse-parallax interaction.

When the user moves the mouse:

- tiger slightly follows/parallax shifts

- background moves at a different depth

- small particles/light elements respond subtly

- UI data elements gently move with the cursor

Do NOT make the animation exaggerated or distracting.

The tiger should feel like it is quietly observing the user.

If a true 3D tiger is not practical, create the effect using layered/high-quality imagery and CSS/JS animation.

The hero should have a premium dark forest/night atmosphere with subtle green/gold wildlife-inspired accents.

Add very subtle floating data elements around the tiger such as:

TIGER ID: PT-017

CONFIDENCE: 97.4%

LAST CAPTURE: 06:42 AM

STATION: PT-04

These should animate very slowly.

VISUAL DESIGN

The design should feel:

- premium

- futuristic

- scientific

- wildlife-focused

- minimal

- cinematic

- trustworthy

Avoid:

- generic corporate templates

- excessive gradients

- excessive rounded cards

- cartoon illustrations

- childish wildlife graphics

- too much text

- overly bright colors

Use a sophisticated palette inspired by the forest:

- deep charcoal / near-black

- forest green

- muted olive

- warm amber/gold

- off-white typography

Typography should be modern and elegant.

Use large editorial-style headings.

---

ANIMATION SYSTEM

Animations are extremely important.

Use:

- smooth page-load animations

- scroll reveal animations

- subtle parallax

- mouse-follow interaction

- floating data cards

- animated map paths

- glowing camera-station markers

- number counters

- hover transitions

- smooth section transitions

Use Framer Motion where appropriate.

Keep animations smooth and performant.

The tiger animation must remain subtle and realistic rather than looking like a game.

Respect "prefers-reduced-motion".

---

RESPONSIVENESS

The entire homepage must be fully responsive.

Desktop:

- cinematic hero

- large tiger visual

- interactive dashboard/map

Tablet:

- reduce visual density

Mobile:

- stacked sections

- hamburger navigation

- tiger remains the main hero visual

- cards become single-column

- map remains readable

- no horizontal scrolling
